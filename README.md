# ResearchNexus - Decentralized Academic Research Platform

A blockchain-based platform enabling transparent academic research collaboration, funding, and peer review on the Stacks blockchain.

## Features
- Research proposal creation and funding
- Collaborative contribution tracking
- Institutional validation system
- Transparent peer review process

## Smart Contract Functions
- `propose-study`: Create new research proposals
- `join-research`: Contribute to existing studies
- `validate-research`: Institutional validation
- `get-study`: Retrieve study details
